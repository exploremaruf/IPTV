# 📺 IPTV

**A curated IPTV playlist for high-quality Bangladeshi and West Bengal (India) television.**

IPTV is a community-driven project dedicated to providing a seamless, high-performance live streaming experience for Bangla speakers globally. This repository maintains a regularly updated `.m3u` playlist designed for maximum compatibility across all modern IPTV ecosystems.

## 🛠 Configuration Guide

### 📱 Mobile & Smart TV (Android / iOS / Fire OS)

1. **Install a client:**
   - Android: [IPTV Pro](https://play.google.com/store/apps) or [TiviMate](https://tivimate.com/)
   - iOS / Apple TV: [IPTV Player](https://apps.apple.com/)
2. **Import playlist:** Select **Add Playlist** and choose the **M3U URL** option.
3. **Deploy:** Paste the URL from the Quick Start section above and save.

### 💻 Desktop (VLC Media Player)

1. Open VLC Media Player.
2. Go to **Media → Open Network Stream** (Shortcut: `Ctrl+N` or `Cmd+Opt+N` on Mac).
3. Enter the playlist URL and click **Play**.
4. **Pro tip:** Use the Playlist View (`Ctrl+L`) to toggle the channel sidebar.

### 🌐 Web-Based Viewing

- Use an HLS/M3U8 Player browser extension (Chrome / Edge / Firefox).
- Alternatively, use a web-based playback tool such as [HLSPlayer.net](https://hlsplayer.net).
